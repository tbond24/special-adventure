Publication remains a deliberate saved-draft review. The image URL is still revoked on every success/failure/superseded path.

**Test harness portability defect (fixed).** Three existing deletion-safety checks failed before reaching the handler because the import-stripping expression expected LF but this Windows checkout uses CRLF. Normalize only the test input; keep the handler's 503 fail-before-deletion policy and dependency unchanged. The three checks now execute and pass. This was not a deletion bypass.
